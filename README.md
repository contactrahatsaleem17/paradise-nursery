# Paradise Nursery

Paradise Nursery is an online houseplant shop built with React and Redux Toolkit.

## About the project

Paradise Nursery lets customers browse houseplants grouped by category, add them to a shopping cart, adjust quantities, and see their running total before checkout.

## Features

- Landing page with a background image, company name, short description, and a "Get Started" button
- Product listing page with 18 houseplants across three categories (Air Purifying, Aromatic, Low Maintenance)
- "Add to Cart" buttons that disable once a plant is in the cart
- Navbar with Home, Plants, and Cart links, plus a live cart count
- Shopping cart page with per-item totals, overall total, quantity controls, delete, checkout, and continue shopping

## Tech stack

- React (Vite)
- Redux Toolkit and React Redux

## Getting started

```bash
npm install
npm run dev
```

To deploy to GitHub Pages:

```bash
npm run deploy
```
